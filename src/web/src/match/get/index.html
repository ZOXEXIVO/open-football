{# The camera controls the replay never says out loud — the transport bar shows the ones it has buttons for, and these have none. Each icon is the input itself with the part that does the work lit, so the picture names the control and the words only have to say what it does. Above the stage rather than below: it is what stands between the header and the replay, so the page needs no padding of its own. Two legends rather than one, because there are two sets of controls: a wheel and a right button on a desktop, a pinch and a stick on a phone (see `src/match/src/touch.rs`). The stylesheet shows whichever belongs to the pointer in use — a phone was previously shown NEITHER, which left the one device whose controls have to be discovered by feel as the one device with nothing to read. #}

{# The loading state, OVER the canvas rather than behind it. Behind it was enough while the placeholder only had to be painted over by the first frame; it is not enough now that the wait has phases, because the canvas is opaque from the first frame the viewer draws and the stadium is not finished for several more. Everything that moves in here moves by `transform` or `opacity`, which is not decoration: linking one of Bevy's shaders blocks the main thread for the better part of four seconds, and an animation the compositor owns is the only kind that keeps running through that. The bar's own width is driven from script and therefore does NOT move during a stall — it steps between them, which is the truth. The phrases are attributes rather than script literals so the translations stay in the template and out of the JavaScript. #}
