# core/club

The club capability models a football club as a set of cooperating domains — academy, boardroom, finances, player relations, staff, team/squad management, and the club's own transfer identity — that each own their slice of state and react to facts reported to them rather than being reached into from outside.

This is a landing page, not an OpenSpec capability — each behavior is documented in one of the child specs below.
