# core/shared

Provide cross-cutting infrastructure shared by every domain module: fast, resilient lookup of world entities by numeric id or URL slug, small display-oriented value types (person names, currency amounts, city locations), and pre-aggregated reporting views built on top of those lookups.

This is a landing page, not an OpenSpec capability — each behavior is documented in one of the child specs below.
