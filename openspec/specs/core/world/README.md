# core/world

Defines how a freshly-loaded world is brought to a runnable, internally consistent state, how unattached players (free agents) enter, wait in, and leave the global market as time passes, and what copying a world guarantees.

This is a landing page, not an OpenSpec capability — each behavior is documented in one of the child specs below.
